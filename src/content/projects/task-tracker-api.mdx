A REST API for creating, updating, and completing tasks, built entirely on
Next.js API routes so it could be deployed as a single Node.js app.

## Stack

- Next.js route handlers for the API layer
- MySQL for storage, using Cloudways' managed database add-on
- Zod for request validation

## What it demonstrates

Running a real backend on Node.js hosting rather than a serverless
function platform, including handling a persistent database connection
pool across requests.
